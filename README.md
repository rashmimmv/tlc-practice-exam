# TLC Practice Exam

A free web-based geography practice quiz for the NYC TLC Driver's License exam.

## About

This site offers a 20-question geography practice exam to help aspiring NYC taxi and for-hire vehicle drivers prepare for the TLC 24-Hour Driver License exam.

Topics covered include NYC borough geography, major landmarks, bridges, tunnels, airports, expressways, and key intersections.

## Features

- 20-question randomized geography quiz
- Instant feedback on each answer
- Score summary at the end
- Mobile-friendly design
- Links to the full TLC Exam Prep app on iOS
